# Azure integration source

Azure configuration, identity, messaging, storage, and Key Vault adapters are
compiled into the `Ifx` assembly. The source targets .NET 10 and retains its
existing public namespaces. Applications use the `Ifx` package reference.

See the [Ifx package guide](../ifx/README.md) for the consolidated dependency
footprint and [project ownership](../../docs/architecture/root-library-consolidation.md).
